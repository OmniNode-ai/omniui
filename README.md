# omniui

OmniNode's shared web component library and rendering runtime: a stateless, browser-safe renderer that draws generic component types (charts, tables, status grids, metric clusters, event feeds) from versioned widget contracts and a shared design-token theme catalog, so every host surface that instantiates it renders from the same source of visual truth instead of hand-forking components per app. This repository is being scaffolded; component code, the token compile pipeline, and the publish path land in the phases that follow.
